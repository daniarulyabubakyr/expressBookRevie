# Online Book Review Application

Modified from the IBM Skills Network starter. See [the repository README](../README.md)
for installation, routes, authentication, Axios tasks and storage behavior.

From this directory:

```sh
npm ci
npm start
```

In another terminal, run `npm test` or, with the application running,
`npm run demo:axios`. Start a fresh application before `npm run evidence`.
See [submission/SUBMISSION.md](submission/SUBMISSION.md) for exact cURL commands
and actual responses.
